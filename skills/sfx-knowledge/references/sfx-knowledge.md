# sfx-knowledge

游戏音效设计实战知识库。每次分析新视频后必须更新本文件末尾的"视频知识追加"区块。
直接用于回答"怎么做某类音效"、"Reaper 里怎么处理"、"这个插件怎么调"等问题。

---

## 一、核心设计哲学

### 1.1 打击感的本质
**打击感 = 瞬态形状，不是低频能量。**
- 遇到"不够有力/不够重"：先动 Transient Shaper 的 Punch/Attack，不要反射性地堆低频 EQ
- 低频堆多了只会让声音变"胖"、变"糊"，不会让人感受到冲击
- 真正的金属撞击感来自：极短的 Attack + 快速衰减的 Decay + 足够宽的动态范围（54+ dB）

### 1.2 效果链是"雕塑"不是"堆砌"
- 每个插件对上一个插件的输出再塑形，是**串联雕塑**
- 不要用并联方式处理撞击音效（并联适合和声类、氛围类）
- 顺序错了整个链路就废：比如先 EQ 再 Decapitator，失真会把 EQ 的塑形完全破坏

### 1.3 物理录音 > 纯合成
- Snow foley（雪箔）、布料摩擦、泡沫塑料敲击 → 天然有机质感
- 合成器（Serum/Wavetable）做**补充层**，不做主体
- 原则：先录物理素材，再用合成器填补缺失的频段或质感

### 1.4 混响/延迟是把双刃剑
- **过量混响会杀死撞击感**：瞬态被淹没在残响里，听起来软糊
- 正确做法：混响 Wet 量用**自动化曲线**控制——撞击瞬间 Wet 最小，衰减段再拉起来
- 延迟同理：过量 Feedback 会让声音失去方向感

### 1.5 对比是最好的品控
- 始终保留未处理（Dry）的原始素材副本
- 对比时**两个版本响度必须一致（Loudness Matching）**，否则响度大的会被误判为"更好"
- DaVinci Resolve 或 DAW 并排波形对比是有效方法

## 二、标准效果链（金属/撞击类）

```
[物理录音素材 / Foley]
        ↓
[Transient Shaper]      ★ 第1步：先定打击感强弱
  Pump → 整体冲击力
  Speed → 瞬态速度/锐利度（快=清脆，慢=厚重）
  Click → 初始咔哒感（金属撞击特有的高频冲击）
  Sustain → 衰减长度
        ↓
[FilterFreak]           ★ 第2步：频率初步雕刻
  Cutoff → 决定音色明暗，金属撞击通常保留中高频
  Resonance → 增加特定频段的金属共鸣感
        ↓
[Valhalla Supermassive] ★ 第3步：加空间（要克制）
  Mode → 选择适合的空间模式
  Wet → 用自动化控制，瞬态时 <15%，衰减段可到 30-40%
  Size → 控制空间大小，撞击音不宜太大
        ↓
[Decapitator]           ★ 第4步：加侵略性
  Drive → 中等过载，目的是加谐波密度而非破音
  Style → A/B/C/D/E 不同谐波特征，金属感选 B/C
  Mix → 通常 40-60%，保留原始动态
        ↓
[Deelay]                ★ 第5步：加层次
  Time → 配合 BPM（如 122 BPM → 1拍 = 490ms）
  Feedback → 低值（10-20%），避免堆积
  Mix → 10-20%，作为空间线索
        ↓
[Doppler Dome]          ★ 第6步：空间运动感（差异化关键）
  移频效果让音效在空间中"飞过"，静态音效没有这个
  用于需要方向感/动态感的撞击（如武器挥击、物体飞过）
        ↓
[EQ（Flux / iZotope Ozone）] ★ 第7步：最终频率微调
  永远是链路最后一步
  目标亮度：2733.6 Hz 附近（neutral，中高频清晰）
  通常做减法：找刺耳的共振频率切掉，而不是大范围提升
        ↓
[iZotope Stereolab]     ★ 可选：立体声宽度
  Width → 适度拓宽，撞击音不宜太宽（会失去冲击的集中感）
  保持低频 Mono（100Hz 以下保持单声道）
```

## 三、逐步制作流程（以金属近战撞击为例）

### Step 1 — 素材采集
- 麦克风录制：snow foley（雪箔）、staff movement（杖/棍挥舞布料声）、styrofoam（泡沫容器敲击）
- 保存原始未处理版本，永远不覆盖
- 3D 动画/视觉参考：明确音效对应的视觉动作时序

### Step 2 — 瞬态初调
- 在 DAW 中打开原始音频（Unprocessed 轨道）
- 针对"spell cast transient"和"staff sweetener"分别做初步 Transient Shaper 调整
- 目标：让 Attack 头部清晰，不要让后续插件处理一个糊成一团的瞬态

### Step 3 — 搭建效果链路由
- 在 Reaper 按上方顺序插入所有插件
- 先 Bypass 所有插件，逐个打开听变化，确认每个插件的作用
- 用 A/B 开关反复对比每个插件 On/Off 的区别

### Step 4 — FilterFreak 滤波
- 先用频谱分析仪看原始素材的能量分布
- 决定要"保留什么、去掉什么"：金属撞击通常保留 200Hz-8kHz
- Cutoff 和 Resonance 配合，让音效有独特的金属共鸣点

### Step 5 — Valhalla Supermassive 混响
- 不要追求"大"，追求"恰到好处的空间感"
- 设置自动化曲线：撞击点前 Wet=0%，撞击后逐渐升到 20-35%
- 听起来不应该像"加了混响"，而是让声音有了"呼吸感"

### Step 6 — Decapitator 失真 + Transient Shaper 精调
- Decapitator 加完后再回头微调 Transient Shaper 的 Pump 值
- 因为失真会改变瞬态的感知，需要重新平衡
- Pump 精调：Speed 和 Click 旋钮小幅度调整即可实现精确动态控制

### Step 7 — Deelay 延迟
- 延迟时间配合视频/游戏的 BPM（122.314 BPM → 四分音符 = 490ms）
- 短延迟（50-150ms）做空间线索，长延迟（490ms+）做节奏层
- Feedback 不超过 20%

### Step 8 — Doppler Dome
- 挥击类、飞行类音效必加
- 调整频率移动的速度和幅度，让音效有"从一侧到另一侧"的动感
- 静态撞击（如垂直落地）可以跳过此步

### Step 9 — Flux EQ / iZotope 均衡
- 频谱分析仪全程开着
- 寻找刺耳的共振峰（通常在 3-6kHz 范围）用窄 Q 值切除
- 检查目标亮度：2733.6 Hz 是中性亮度参考
- EQ 操作幅度通常 ±3-6 dB，不要大幅增益

### Step 10 — 多轨混音与自动化
- 每条素材轨道有独立效果链（不要全部过一条主轨）
- 音量推子（Volume Fader）+ 声像（Pan）精调
- 用包络线（Envelope）控制整体动态变化
- 自动化曲线：让音效在时间轴上有"故事性"，而不是一个静态的声音

### Step 11 — 前后对比与迭代
- 创建 A/B 对比：Unprocessed vs Processed
- 响度归一化后听，不被响度欺骗
- 根据听感反馈回头调整参数，至少迭代 2-3 轮

### Step 12 — 合成器补充层（可选）
- Serum / Wavetable / ShapeTable：加 LFO 调制、滤波器包络
- 用于填补 Foley 录音中缺失的频段（如超低频冲击感或超高频金属光泽）
- 合成层通常 Mix 在 20-40%，以 Foley 为主体

### Step 13 — MIDI 编程时序
- BPM 精确设定（参考：122.314 BPM）
- Velocity 调整控制每次撞击的力度变化
- 音符时间精确对齐视觉帧

### Step 14 — 渲染导出
- 渲染前检查：响度、亮度、动态范围（见下方参考值）
- 格式：WAV 44.1kHz / 48kHz，24bi
- 保留 Wet Mix 版本和 Dry 版本，方便后续在 FMOD 中混合调整

## 四、渲染目标参考值（金属撞击）

| 参数 | 参考值 | 含义 |
|------|--------|------|
| 响度（RMS） | **-21.52 dBFS** | moderate，保留混音余量 |
| 亮度（谱心频率） | **2733.6 Hz** | neutral，中高频清晰不刺耳 |
| 动态范围 | **54.72 dB** | wide，瞬态和衰减对比鲜明 |
| 采样率 | 44.1 kHz 或 48 kHz | 视项目要求 |
| 位深 | 24-bit | 标准 |

## 五、插件速查手册

### Transient Shaper
```
用途：整形音频的 Attack 和 Sustain 部分
关键参数：
  Punch / Attack  → 控制初始冲击力度（最重要的参数）
  Speed           → 瞬态的持续时间（快=清脆金属，慢=厚重木头）
  Click           → 极短的高频冲击感（金属特有）
  Sustain         → 衰减段长度控制
使用时机：
  ① 效果链第一个插件使用（最重要）
  ② Decapitator 后微调第二次（因失真改变了瞬态感知）
```

### FilterFreak（Soundtoys）
```
用途：频率滤波 + 共鸣塑形
关键参数：
  Cutoff          → 截止频率，决定通过哪些频率
  Resonance       → 共鸣峰值，金属感的来源之一
  Filter Type     → LP（低通）/ HP（高通）/ BP（带通）
使用时机：效果链第二步，在 Transient Shaper 之后
```

### Valhalla Supermassive
```
用途：混响 + 空间感
关键参数：
  Mode            → 不同空间算法（Metal/Halls/Plate等）
  Feedback        → 混响密度和扩散程度
  Wet             → 混响量（★ 用自动化曲线控制）
  Width           → 立体声宽度
使用时机：效果链第三步，失真之前（失真在混响后效果更好）
```

### Decapitator（Soundtoys）
```
用途：模拟磁带/电子管失真，增加谐波密度和侵略性
关键参数：
  Drive           → 过载量，中等即可（不是为了破音）
  Style A/B/C/D/E → 不同谐波特征（B/C 更适合金属撞击）
  Mix             → 干湿比，通常 40-60%
  Punish          → 极端过载（谨慎使用）
使用时机：效果链第四步（混响之后，延迟之前）
```

### Deelay（Baby Audio）
```
用途：延迟效果，创建回声和空间纵深
关键参数：
  Time            → 延迟时间（对齐 BPM：122.314 BPM → 490ms/拍）
  Feedback        → 回声次数（10-20%，避免堆积）
  Mix             → 延迟量（10-20%）
使用时机：效果链第五步（失真之后，Doppler 之前）
```

### Doppler Dome
```
用途：多普勒移频效果，模拟音源在空间中移动
关键参数：
  Speed           → 频率移动速度
  Depth           → 移频幅度
使用时机：挥击/飞行类音效必用，静态撞击可跳过
注意：这是区分"有动感"和"没动感"音效的关键插件
```

### Flux Equalizer / iZotope Ozone EQ
```
用途：最终频率微调
使用原则：
  ① 永远是链路最后一步
  ② 以减法为主：找刺耳的共振峰切掉（窄 Q 值）
  ③ 参考频谱分析仪，不要凭感觉乱 boos
  ④ 目标：2733.6 Hz 附近中性亮度
```

### iZotope Stereolab
```
用途：立体声宽度处理
关键参数：
  Width           → 立体声宽度（撞击类不宜过宽）
  Low Mono        → 低频保持单声道（100Hz 以下 Mono）
使用时机：效果链最末（EQ 之后）
```

### Serum / Wavetable / ShapeTable
```
用途：合成器补充层
关键参数：
  Oscillator      → 波形选择（金属感选 FM / Wavetable 复杂波形）
  Filter Envelope → 包络控制频率变化，模拟金属衰减
  LFO             → 调制振荡，增加动态感
使用时机：Foley 为主体，合成器做补充（Mix 20-40%）
```

## 六、问题诊断速查

| 问题现象 | 诊断 | 解法 |
|----------|------|------|
| 撞击感弱，不够有力 | 瞬态不够锐利 | ↑ Transient Shaper Punch + Attack，不要 boost 低频 |
| 声音太干、太死 | 缺乏空间感 | 加 Valhalla Supermassive，Wet 用自动化曲线 |
| 有空间感但撞击被淹没 | 混响 Wet 太大 | Wet 自动化：撞击瞬间降到 <15% |
| 听着很平，没有动感 | 缺少运动感 | 加 Doppler Dome，或 Deelay 短延迟 |
| 声音太尖刺耳 | 高频共振峰 | EQ 用窄 Q 值在 3-8kHz 找峰值切掉 |
| 声音太暗不清晰 | 中高频不足 | EQ 在 2-4kHz 温和提升（≤ 3dB）|
| 加了失真反而更糊 | 顺序错了 | Decapitator 必须在 Transient Shaper 之后，不能在之前 |
| 前后对比难以判断 | 响度不匹配 | 两个版本用响度归一化对齐后再比较 |
| 声音"假"，缺乏真实感 | 全靠合成，缺 Foley | 先录物理素材（snow foley / 布料 / 泡沫），再叠合成层 |
| 多轨混音层次不清 | 各轨频段重叠 | 用 EQ 给每条轨道划分频段，Low/Mid/High 各司其职 |

## 七、素材采集技巧

- **Snow Foley（雪箔）**：薄金属箔搓揉，模拟金属滑动/碰撞的高频光泽
- **Staff Movement（杖挥舞）**：带布料的棍棒快速挥舞，产生空气切割感
- **Styrofoam（泡沫容器）**：敲击泡沫产生的低频闷响，是金属重量感的来源
- 录音环境：专业录音棚（控制室内反射），减少不必要的房间混响
- 始终录制多次，选最清晰的 Take，不要将就用第一条

## 八、在 FMOD 中的对接建议

- 导出**Dry 版本**（无混响延迟）到 FMOD，在 FMOD 内加 Reverb Send，便于游戏内实时控制空间感
- 导出时建议同时有：纯冲击版（短）+ 完整版（含混响尾音）两个文件
- FMOD 内用 Parameter 控制 Reverb Send 量，实现不同场景（室内/室外）的自动切换
- 响度目标：-21.52 dBFS，这个值和游戏内混音总线的增益预留匹配

### [2026-05-09] 视频：游戏暴力音效设计 Overkill库应用（ID: -vxdSIdNAw4）
**来源**：YouTube，Rock The Speakerbox Overkill音效库评测，10.5分钟，音频特征 quiet/neutral/wide（动态范围60.74dB）
**视频主题**：专业gore/暴力类游戏音效的分层合成工作流，使用预制音效库+合成器改造

**新增知识：**

**1. 时间拉伸是改变音效性格最快的手段（本视频核心技术）**
- 同一个素材通过不同播放速率完全改变质感
- 常用速率范围：0.025（超慢速，戏剧性拉伸）→ 1.762（加速）
- 具体用过的值：0.282 / 0.572 / 0.821 / 1.094x / 1.116x / 1.205x / 1.215x / 1.762x
- 0.025 倍速专用于刀片滑动音效，配合 EQ 削减 -63.97Hz（刺耳金属谐波点）

**2. 颗粒合成创建"超真实"质感**
