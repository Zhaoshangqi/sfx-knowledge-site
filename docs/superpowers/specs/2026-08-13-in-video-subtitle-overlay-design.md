# 画内中文字幕设计规格

## 背景

当前播放器把正在播放的字幕放在视频下方，只在站内全屏时额外显示画内字幕。普通播放需要在画面和字幕之间来回移动视线，也容易让用户误以为进入全屏后本站字幕会消失。

本次采用已确认的 A 方案：当前字幕始终显示在视频画面底部安全区，普通播放与站内全屏使用同一字幕表面和同一同步逻辑。

## 目标

- 当前字幕在普通播放和站内全屏中始终位于视频画面内。
- 字幕避开 YouTube 底部控制栏，保持清楚、简洁、最多两行。
- `CC` 按钮继续控制本站字幕，不依赖 YouTube 官方字幕或自动翻译。
- 保留逐句跳转能力，但“字幕全文”默认收起，避免挤占学习内容。
- 无本站字幕的视频仍可正常播放，不显示空字幕底框。
- 桌面、手机竖屏和手机横屏均无溢出、遮挡或跳动。

## 非目标

- 不新增字幕上移、拖动、字号或颜色设置。
- 不接入 YouTube 官方翻译字幕。
- 不修改字幕数据格式、字幕审核状态或 WebVTT 转换流程。
- 不改变视频下载、存储或播放来源。

## 交互设计

### 当前字幕

- 当前句显示在 `.video-player-stage` 内的现有画内字幕节点上。
- 普通播放和站内全屏都显示同一节点，不再只在 `:fullscreen` 状态下启用。
- 字幕水平居中，左右安全边距合计至少占画面宽度的 14%，文字区域最大宽度约为画面宽度的 86%。
- 字幕位于 YouTube 控制栏上方。普通尺寸使用 `clamp(56px, 10%, 84px)` 的底部避让空间；全屏使用 `clamp(72px, 8%, 112px)`。
- 单句最多显示两行且不得截断或显示省略号。字幕数据转换流程负责拆分过长内容并保留完整文字与时间顺序；CSS 只负责换行和稳定显示区域。
- 深色半透明背景只包围文字区域，不铺满整条画面；文字使用白色和轻微阴影保证复杂画面上的可读性。
- 字幕节点不接收指针事件，不能阻挡 YouTube 播放、暂停或进度条操作。

### 字幕控制

- `CC` 按钮保留现有行为，同时控制画内字幕和无障碍当前句。
- 关闭字幕后立即清空画内文字和无障碍播报内容；重新开启后恢复当前时间点对应字幕。
- 无字幕视频的 `CC` 按钮保持禁用，播放器继续显示“中文字幕整理中”的状态。

### 字幕全文

- 移除播放器下方可见的“当前句”重复显示。
- 原有逐句列表放入默认关闭的原生 `<details>` 区域，摘要文字为“字幕全文”。
- 展开后仍显示时间码、逐句文字和当前句高亮；点击句子仍会播放并跳转到对应时间。
- 收起列表不会停止当前句同步，也不会改变字幕开关状态。
- 站内全屏隐藏字幕全文区域，只保留画内字幕和播放器控制。

### 全屏

- 全屏按钮继续对完整 `.video-player` 容器调用 Fullscreen API，不对 YouTube iframe 单独全屏。
- YouTube 原生全屏入口继续关闭，避免 iframe 独占全屏后排除本站字幕层。
- 进入和退出全屏不重建播放器，不重置播放时间、字幕开关或当前句。

## 数据流

1. `SfxVideoSubtitles.trackFor(videoId)` 返回站内字幕轨。
2. 播放器每 200 ms 读取当前播放时间，并通过 `cueAt(track, time)` 找到当前句。
3. 同一同步函数更新画内字幕、无障碍当前句和逐句列表高亮。
4. `CC` 关闭时同步函数保留时间与高亮状态，但不输出可见字幕或无障碍播报。
5. 字幕轨缺失、时间无效或播放器尚未准备好时，画内字幕保持空且无背景。

## 响应式规则

- 桌面普通播放：字幕字号约 16 px，左右安全边距 7%，底部避开控制栏。
- 桌面全屏：字幕字号约 20 px，仍限制为两行，不随视口宽度无限放大。
- 手机竖屏：字幕字号约 14 px，左右安全边距 4%，底部避让按紧凑播放器高度调整。
- 手机横屏或手机全屏：字幕字号约 16 px，保持画内居中，不覆盖系统安全区域。
- 所有尺寸都使用稳定的 16:9 播放区域；字幕出现、消失或换行不得改变播放器尺寸。

## 错误与降级

- 浏览器不支持 Fullscreen API 时，全屏按钮保持禁用，普通播放的画内字幕仍正常工作。
- YouTube IFrame API 加载失败时沿用现有错误提示，字幕层保持空，不展示与播放时间不对应的文本。
- 字幕轨不存在或校验失败时按无字幕状态处理，不生成占位字幕。
- 本站字幕与 YouTube 原生字幕抑制相互独立；即使原生字幕抑制失败，本站字幕同步也不受影响。

## 验收标准

- 有字幕视频在普通播放时，当前句只在画面内可见，下方不再重复显示。
- 同一视频进入站内全屏后，当前句继续同步且位置稳定。
- 字幕不会覆盖 YouTube 底部控制栏，最多显示两行，背景只包围文字。
- 任一字幕句都不会因两行限制被截断或显示省略号。
- `CC` 开关在普通播放和全屏中都立即生效。
- “字幕全文”默认收起，展开后点击任一句仍能跳转并播放。
- 无字幕视频不显示空字幕背景，`CC` 禁用，视频仍能播放。
- 桌面与手机视口均无横向溢出或控件重叠。

## 测试范围

- 更新播放器渲染测试，验证画内字幕节点在普通状态可见，字幕全文默认收起。
- 更新同步测试，验证画内字幕、无障碍内容和列表高亮使用同一当前句。
- 覆盖 `CC` 开关、无字幕状态、逐句跳转、播放器销毁和全屏切换。
- 运行现有 Node、Python 与 portable-kit 全量回归。
- 用真实 YouTube iframe 在桌面、手机竖屏、手机横屏和站内全屏中做视觉验收，并检查控制栏遮挡、两行限制和页面溢出。
