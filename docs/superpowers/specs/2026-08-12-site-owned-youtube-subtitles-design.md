# 站内 YouTube 播放与自有中文字幕设计

## 状态

- 方向已由用户批准：视频继续由 YouTube 承载，中文字幕由本站保存、修订和同步显示。
- 首个端到端样板使用 `Xl5u91oQv-k`，随后按同一数据契约扩展到其余视频。
- 本功能只提交字幕文本、代码和状态元数据，不提交原始 YouTube 视频、音轨、Cookie 或登录态。

## 目标

1. 视频详情页直接播放对应 YouTube 视频，不跳出网站。
2. 播放器只在用户点击封面后加载，避免 82 个 iframe 同时请求。
3. 播放时根据 YouTube IFrame Player API 的当前时间显示本站自己的简体中文字幕。
4. 普通模式把字幕放在播放器下方，避免遮挡效果器界面；站内全屏时把字幕覆盖在画面底部。
5. 提供字幕开关、站内全屏、逐句字幕列表和点击字幕跳转。
6. 每条视频明确显示字幕状态，不把缺失、机器初稿或已校对字幕混为一谈。
7. 字幕数据随 GitHub Pages 静态站点发布，播放时不调用 YouTube 自动翻译。

## 架构

### 字幕数据层

- `src/video-subtitles.js` 使用 UMD/CommonJS 形式保存站内字幕轨道和查询方法。
- 每条轨道包含 `videoId`、`language`、`source`、`reviewStatus`、`updatedAt` 和按开始时间排序的 `cues`。
- cue 使用 `{ start, end, text }`，单位为秒。模块负责校验、二分查找当前 cue、格式化时间和计算覆盖状态。
- 首个样板从公开英文自动字幕和简体中文草稿建立时间轴，再保存为本站独立副本；状态明确标记为“机器初稿，术语已初步校正”，不冒充人工终审。

### 播放器层

- `src/youtube-caption-player.js` 负责生成播放器外壳、懒加载 IFrame API、创建/销毁播放器、轮询当前时间、切换字幕和站内全屏。
- 页面同一时间只保留一个活跃播放器。离开视频详情或切换视频时销毁旧实例和计时器。
- YouTube 原生字幕默认关闭，原生全屏按钮关闭；本站提供包裹 iframe 与字幕层的全屏按钮，保证字幕随画面进入全屏。
- `playsinline=1` 保持移动端尽量在页面内播放。设备不支持容器全屏时隐藏或禁用站内全屏按钮，视频与字幕仍可正常使用。

### 页面接入

- 视频详情在“设计思路”之后显示播放器，再进入素材、步骤和效果链内容。
- 有字幕时显示当前字幕、字幕状态和完整逐句列表；无字幕时仍可播放，并显示“中文字幕整理中”。
- 点击字幕行调用 `seekTo(start, true)` 并继续播放；当前字幕行使用 `aria-current` 标记。
- 原始视频链接继续保留在来源区域，作为外部查看的退路。

## 字幕生产流程

1. 使用 `yt-dlp --skip-download --write-auto-subs` 只获取公开字幕文本，不下载视频媒体。
2. 优先保存原始语言轨道；可用的 YouTube 中文轨道仅作翻译草稿和时间轴参考。
3. `tools/build-site-subtitles.cjs` 解析 VTT、去除滚动重复、合并过短片段、清理标签，并输出稳定 cue 数据。
4. 对效果器名、厂商名、DAW、音频术语和明显误译进行人工或模型校正。
5. 校验 cue 单调、无非法时间、无空文本、时长范围合理，再写入站内字幕模块。
6. 更新轨道状态：`draft`、`reviewed` 或 `unavailable`。没有真实字幕证据时保持缺失，不生成虚构字幕。

## 视觉与交互

- 播放器保持 16:9，封面使用现有 YouTube 缩略图。
- 普通模式字幕是播放器正下方的固定高度文本条，最多两行，动态内容不推动后续章节跳动。
- 站内全屏时字幕条覆盖在底部控制安全区上方，背景保证可读性，且不接收指针事件。
- 字幕列表使用紧凑行，不做装饰卡片；当前行突出显示并自动滚到可见范围。
- 控件必须可键盘操作并有明确可访问名称，字幕状态通过 `aria-live` 更新。

## 验证

- Node 测试覆盖轨道校验、二分查找、边界时间、覆盖状态、播放器参数、HTML 转义和生命周期契约。
- 站点集成测试确认脚本顺序、播放器位置、懒加载入口、字幕状态和旧“打开原视频”退路。
- 浏览器验收覆盖真实 YouTube 播放器创建、字幕随时间切换、点击字幕跳转、字幕开关、站内全屏、视频切换销毁，以及桌面和手机无重叠。
- 全量运行现有 Node/Python 测试、便携包验证、脚本语法检查和 `git diff --check`。

## 非目标

- 不把字幕注入 YouTube iframe 内部。
- 不在仓库中保存原始视频或完整音轨。
- 不假定所有视频都有公开字幕；缺失视频进入可追踪的待转写队列。
- 不把机器翻译状态展示成已人工校对。
