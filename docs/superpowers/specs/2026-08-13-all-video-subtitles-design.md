# 全量视频中文字幕设计

## 状态

- 用户已批准为网站全部 82 条视频补齐可用的站内中文字幕状态。
- 现有 YouTube 播放与站内字幕覆盖层保持不变；本次扩展字幕数据、批量生产流程和无口述状态。
- 字幕用于辅助观看和定位，不替代视频画面证据，也不自动改变现有视频分析结论。

## 目标

1. 让每条视频详情都具有明确、可验证的中文字幕结果：字幕轨道、无口述状态或真实失败状态。
2. 播放时继续使用 YouTube，字幕由本站静态资源提供，不调用 YouTube 运行时翻译。
3. 公开自动字幕和本地语音转写统一标为机器初稿，不冒充人工终审。
4. 不提交原始视频、完整音轨、Cookie、登录态、令牌或临时转写文件。
5. 控制首页负载：只在打开对应视频详情时加载该视频的字幕正文。

## 数据架构

### 字幕索引

- `src/video-subtitles.js` 保留查询、时间格式化、cue 查找和覆盖统计逻辑。
- 模块内只保存轻量字幕清单：`videoId`、语言、来源、审阅状态、更新时间、资源路径和内容状态。
- 内容状态包括：
  - `draft`：存在机器字幕正文，尚未人工逐句校对。
  - `reviewed`：时间轴、正文和术语已经人工核对。
  - `no-speech`：已检查音频，没有可转写口述，不显示伪造字幕行。
  - `missing`：字幕获取或转写真实失败；视频仍可播放，并明确显示原因。

### 字幕正文

- 每条有口述的视频使用独立的 `assets/subtitles/<videoId>.json`。
- JSON 沿用 `{ videoId, language, source, reviewStatus, updatedAt, cues }` 契约。
- 播放器进入对应详情时才异步加载正文，并缓存本次页面会话已经加载的轨道。
- 加载中显示稳定状态；失败时保持播放器可用，并降级为明确的字幕不可用提示。

## 生产流程

### 75 条公开字幕

1. 用 `yt-dlp --skip-download --write-auto-subs` 获取 `zh-Hans` 和 `en-orig` VTT，不下载媒体。
2. 使用现有 WebVTT 转换器清除滚动重复、标签、纯音乐提示、空文本和重叠时间段。
3. 用英文轨、视频标题和现有记录核对产品名、插件名、DAW 名及常见音频术语。
4. 中文自动翻译一律写为 `draft`，来源写为 `site-owned-from-public-captions`。
5. 现有 `Xl5u91oQv-k` 字幕保留已校正术语，并迁移到独立 JSON，不降低已有质量。

### 7 条无公开字幕视频

1. 只把临时音频下载到 Git 忽略的 `.work/subtitles/`，不读取浏览器 Cookie，不提交媒体。
2. 使用带 VAD 的本地语音识别生成时间轴；模型输出只能作为 `draft`。
3. 对低置信度片段、音效演示和音乐段落执行失败关闭：不把噪声或音效识别结果写成台词。
4. 若检查后存在口述，生成来源为 `site-owned-from-local-transcription` 的字幕轨道。
5. 若检查后确实没有口述，记录为 `no-speech`，页面显示“本视频无口述内容”。
6. 若媒体无法取得或无法可靠判断，保持 `missing` 并记录具体原因，不用网站摘要补造字幕。

## 批量工具与可重复性

- 新增受测的字幕清单和批量导入工具，从网站记录生成唯一的 82 条视频清单。
- 工具必须支持断点续跑，已验证输出默认不重复下载或覆盖。
- 每条轨道单独校验后原子写入，单条失败不会破坏其他字幕。
- 生成覆盖报告，至少包含总数、公开字幕数、本地转写数、无口述数、失败数和 cue 总数。
- `.work/` 只保存临时输入、下载日志和中间结果；仓库只提交站点字幕 JSON、索引、代码、测试及文档。

## 页面行为

- 打开视频详情后先渲染播放器，再加载对应字幕，不阻塞页面导航。
- 有字幕时沿用现有画面内字幕、字幕开关、逐句列表、点击跳转和站内全屏。
- `draft` 统一显示“机器字幕初稿，待人工校对”；`reviewed` 显示“中文字幕已校对”。
- `no-speech` 显示“本视频无口述内容”，不渲染空的逐句列表。
- `missing` 显示可读失败状态，禁止把“整理中”伪装成已经覆盖。

## 验证

1. 单元测试覆盖字幕清单校验、按需加载、缓存、网络失败降级、状态统计和 82 条唯一覆盖。
2. 转换测试覆盖真实公开 VTT、空轨、噪声提示、滚动重复、异常时间轴和确定性输出。
3. 全量内容审计确认所有字幕文件都对应现有 `videoId`，cue 单调且不重叠，文本非空且显示长度受控。
4. 浏览器验收至少抽查短视频、长视频、公开字幕、本地转写、无口述和失败状态，并覆盖桌面、390px 手机与横屏全屏。
5. 发布前运行全部 Node/Python 测试、便携包检查、脚本语法检查和 `git diff --check`。
6. 最终报告精确给出 82 条中的字幕轨道、无口述和失败数量；只有轨道或已核验无口述状态才计入完成覆盖。

## 非目标

- 不人工逐句终审全部机器翻译，也不把机器初稿升级为 `reviewed`。
- 不下载或托管完整 YouTube 视频。
- 不从现有摘要、步骤或效果器描述反向生成伪字幕。
- 不绕过 DPAPI、浏览器 Cookie、登录令牌或 YouTube 的安全边界。
